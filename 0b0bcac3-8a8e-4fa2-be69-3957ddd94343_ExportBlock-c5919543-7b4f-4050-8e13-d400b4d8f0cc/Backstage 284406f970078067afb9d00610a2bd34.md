# Backstage

**後台架構設計：**

## **1. 角色權限**

**管理員 (Admin)**

- 查看所有用戶數據
- 系統設定控制
- 機器人啟動/停止
- 風險參數調整

**使用者 (User)**

- 僅看自己數據
- 個人策略設定
- 查看收益記錄

---

## **2. 功能模組拆解**

### **A. 管理員後台**

**系統控制面板**

```
- 機器人狀態監控（運行/停止/錯誤）
- 緊急停止按鈕
- 全域策略切換（市場跟隨/階梯式/組合）
- API 連線狀態
- 系統日誌查看
```

**用戶管理**

```
- 用戶列表（5 個初始用戶）
- 新增/停用用戶
- API Key 綁定管理
- 權限分配
```

**全域設定**

```
- 風險參數（最低利率、單筆上限）
- 更新頻率（5-10 分鐘）
- 通知設定（Telegram Token）
- 緊急停止條件設定
```

**數據總覽**

```
- 總資金量
- 總收益（所有用戶）
- 平均資金使用率
- 系統運行時間
```

---

### **B. 使用者後台**

**儀表板（Dashboard）**

```
核心指標（卡片式呈現）：
├── 總資產（USD）
├── 當日收益
├── 累計收益
├── 資金使用率（進度條）
└── 年化報酬率

即時狀態：
├── 當前掛單列表（利率、金額、期限）
├── 進行中放貸（到期時間、利息）
└── 最近成交記錄（時間、金額、利率）

圖表視覺化：
├── 收益趨勢圖（折線圖，7/30 天）
├── 資金使用率歷史（面積圖）
└── 利率分布（柱狀圖）
```

**策略設定**

```
基礎設定：
├── 啟用/停用機器人（開關）
├── 選擇策略（下拉選單）
│   ├── 市場跟隨
│   ├── 階梯式
│   └── 組合策略
└── 幣種選擇（USD/USDT）

進階參數：
├── 最低利率閾值（滑桿）
├── 期限偏好（2/7/30 天）
├── 市場跟隨 -X%（輸入框）
└── 階梯式比例設定

風險控制：
├── 單筆最大金額
├── 保留閒置資金（%）
└── 自動複投開關
```

**歷史記錄**

```
放貸記錄：
- 表格：時間、金額、利率、期限、狀態、收益
- 篩選：日期範圍、狀態（進行中/已完成）
- 導出 CSV

訂單記錄：
- 掛單/取消/成交歷史
- 時間軸呈現

系統通知：
- API 錯誤
- 成交通知
- 到期提醒
```

**帳戶設定**

```
API 管理：
├── Bitfinex API Key 設定
├── API 權限檢查（只讀顯示）
└── 測試連線按鈕

通知設定：
├── Telegram Bot Token
├── 通知開關（成交/錯誤/每日報告）
└── Email 設定（選用）

安全設定：
├── 修改密碼
└── 登出其他裝置
```

## **4. 後端 API 端點設計**

```
認證：
POST /api/auth/login
POST /api/auth/logout
GET  /api/auth/me

管理員：
GET  /api/admin/users (列表)
POST /api/admin/users (新增)
PUT  /api/admin/bot/control (啟動/停止)
GET  /api/admin/system/status
GET  /api/admin/logs

使用者：
GET  /api/user/dashboard (儀表板數據)
GET  /api/user/offers (掛單列表)
GET  /api/user/history (歷史記錄)
PUT  /api/user/strategy (更新策略)
POST /api/user/bot/toggle (啟停機器人)

通用：
GET  /api/market/rates (即時利率)
GET  /api/stats/performance (績效統計)
```

## **5. 資料庫結構（簡化）**

```sql
users (用戶表)
├── id
├── email
├── role (admin/user)
├── api_key_encrypted
└── created_at

strategies (策略設定)
├── user_id
├── strategy_type
├── min_rate
├── duration_preference
└── params (JSON)

offers (掛單記錄)
├── user_id
├── amount
├── rate
├── duration
├── status
└── created_at

loans (放貸記錄)
├── user_id
├── offer_id
├── amount
├── rate
├── start_date
├── end_date
└── earnings

logs (系統日誌)
├── level
├── message
├── user_id
└── timestamp
```
