# 專案簡介

## 📖 專案背景

在加密貨幣市場中，Bitfinex 提供了融資借貸（Margin Funding）功能，允許用戶將閒置的美元或穩定幣借貸給其他交易者，從而賺取利息收益。然而，手動管理放貸需要：

- 持續監控市場利率
- 及時調整掛單策略
- 處理到期資金再投資

這個過程耗時且效率低下，因此需要一個自動化解決方案。

---

## 🎯 專案定位

**Bitfinex 放貸機器人**是一個自動化放貸管理系統，提供：

1. **自動化放貸**：根據市場利率自動掛單
2. **策略管理**：支援多種放貸策略
3. **風險控制**：設定安全參數避免虧損
4. **數據追蹤**：完整的收益與歷史記錄
5. **多用戶支援**：可服務多個用戶

---

## 📊 市場分析

### 目標用戶群
1. **持幣者**：有閒置 USD/USDT 想賺取收益
2. **量化交易者**：希望最大化資金使用率
3. **機構投資者**：大額資金需要自動化管理

### 市場需求
- Bitfinex 每日放貸量級：數億美元
- 平均年化利率：5-15%（依市場波動）
- 現有解決方案：大多為手動或簡陋的腳本

## 🛠️ 技術特點

### 架構設計
- **前後端分離**：現代化開發模式
- **微服務化**：機器人與 API 分離
- **可擴展性**：支援水平擴展

### 技術亮點
- **React 18 + TypeScript**：類型安全的現代前端
- **FastAPI**：高性能異步後端
- **shadcn/ui**：精美的 UI 組件庫
- **PostgreSQL**：可靠的數據存儲
