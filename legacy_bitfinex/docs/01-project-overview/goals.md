# 專案目標

## 🎯 核心目標

### 1. 自動化放貸（必須）
**目標**：實現 24/7 自動化資金放貸

**具體要求**：
- ✅ 每 5-10 分鐘檢查市場利率
- ✅ 根據策略自動掛單/取消訂單
- ✅ 到期資金自動再投資
- ✅ 異常情況自動告警

**成功標準**：
- 機器人連續運行 > 30 天無人工介入
- 資金使用率 > 90%
- 執行延遲 < 1 分鐘

---

### 2. 策略管理（必須）
**目標**：提供靈活的放貸策略配置

**支援策略**：

#### a. 市場跟隨策略
```
掛單利率 = 市場平均利率 × (1 - X%)
適用：穩健型，成交率高
```

#### b. 階梯式策略
```
資金分層：
- 30% @ 市場利率 - 5%
- 40% @ 市場利率
- 30% @ 市場利率 + 5%
適用：平衡風險與收益
```

#### c. 組合策略（未來）
```
根據市場波動度動態調整
```

**成功標準**：
- 用戶可自由切換策略
- 策略參數可調整
- 策略變更 < 5 分鐘生效

---

### 3. 風險控制（必須）
**目標**：確保用戶資金安全

**風控機制**：
- ✅ 最低利率閾值（如 > 0.01% daily）
- ✅ 單筆最大金額限制
- ✅ 保留閒置資金比例
- ✅ 緊急停止按鈕
- ✅ API 權限檢查（只允許 Margin Funding）

**成功標準**：
- 零資金損失事件
- 惡意攻擊有效防範
- 異常立即通知

---

### 4. 用戶體驗（必須）
**目標**：提供現代化、易用的管理界面

**功能需求**：

#### 儀表板
- 總資產展示
- 當日/累計收益
- 資金使用率
- 收益趨勢圖
- 即時掛單狀態

#### 歷史記錄
- 所有放貸記錄
- 可篩選、排序
- 匯出 CSV

#### 策略設定
- 直觀的參數調整
- 即時預覽效果
- 一鍵啟停機器人

**成功標準**：
- 新用戶 < 10 分鐘完成設定
- 操作無需文檔即可理解
- 移動端可查看（響應式）

---

### 5. 通知系統（必須）
**目標**：即時掌握機器人狀態

**通知類型**：
- 🎯 成交通知（放貸成功）
- ⚠️ 錯誤告警（API 失敗、餘額不足）
- 📊 每日報告（收益統計）
- 🛑 緊急停止（系統異常）

**通知渠道**：
- Telegram Bot（必須）
- Email（選用）

**成功標準**：
- 通知延遲 < 30 秒
- 通知到達率 > 99%
- 無垃圾通知

---

### 6. 多用戶支援（必須）
**目標**：一套系統服務多個用戶

**需求**：
- 每個用戶獨立 API Key
- 用戶間數據完全隔離
- 管理員可監控所有用戶
- 支援角色權限（Admin/User）

**成功標準**：
- 5 個用戶同時穩定運行
- 無跨用戶數據洩漏
- 管理員可快速排查問題

---

## 📊 非功能性需求

### 性能需求
| 指標 | 目標值 |
|------|--------|
| API 響應時間 | < 200ms (P95) |
| 機器人執行週期 | 5-10 分鐘 |
| 前端首屏加載 | < 2 秒 |
| 資料庫查詢 | < 100ms |

### 可用性需求
- 系統正常運行時間 > 99%
- 計劃性維護時間 < 1 小時/月
- 故障恢復時間 < 15 分鐘

### 安全性需求
- API Key 加密存儲（AES-256）
- HTTPS 強制加密
- JWT Token 有效期 24 小時
- 密碼 bcrypt 加密（cost > 12）
- SQL 注入防護
- CSRF 防護

### 擴展性需求
- 支援水平擴展（多機器人實例）
- 資料庫支援讀寫分離（未來）
- 可承受 50+ 用戶（未來）

---

## 🚫 非目標（Not Goals）

明確 **不在** 本專案範圍內的功能：

❌ 支援現貨交易（只做 Margin Funding）
❌ 支援其他交易所（MVP 只支援 Bitfinex）
❌ 移動 App（僅 Web）
❌ 社群功能（策略分享）
❌ 自動套利（只做放貸）
❌ AI 智能預測（未來可能加入）
